## Work Done

### 1. FastAPI Backend (`src/api.py`)
- Built a REST API with **FastAPI** to expose the TexTailor pipeline over HTTP.
- `POST /api/generate` — accepts a job description, spins up the pipeline in a background thread, returns a `task_id`.
- `GET /api/status/{task_id}` — polls live step-by-step progress (parse → recruiter → rewrite → compile → ATS score).
- `GET /api/pdf/{task_id}` — serves the tailored resume PDF once ready.
- `GET /api/template` — serves the base resume template PDF.
- Added CORS middleware to allow requests from Angular dev server (`http://localhost:4200`).
- 5-step pipeline tracked with per-step status, elapsed time, and detail messages.

### 2. Angular UI (`ui/`)
- Bootstrapped Angular 22 project with standalone components.
- `ResumeService` (`ui/src/app/resume.service.ts`) — handles API calls: trigger generation, poll status, fetch PDF.
- `AppComponent` (`ui/src/app/app.ts`) — main UI with job description input, live pipeline progress tracker, ATS score display, and PDF viewer.
- Styled with custom SCSS (`app.scss`, `styles.scss`) — 418 lines of component styling.
- Full HTML template (`app.html`) — 130 lines covering all UI states (idle, running, done, error).

## Pipeline Flow (as implemented in `api.py`)

```
POST /api/generate (jd text)
        │
        ▼
  [Step 1] Parse resume (.tex → sections + plain text)
        │
        ▼
  [Step 2] Recruiter analysis (missing keywords, job title)
        │
        ▼
  [Step 3] Rewrite sections (Claude-powered tailoring)
        │
        ▼
  [Step 4] Patch .tex + compile PDF (pdflatex)
        │
        ▼
  [Step 5] ATS score + report (overall score %, verdict)
        │
        ▼
  GET /api/pdf/{task_id} → tailored resume PDF
```
